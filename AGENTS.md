# Student hub

- `README.md` owns the update workflow and live URLs. "Update the student link"
  authorizes rebuilding the completed student materials, pushing to this repository,
  and verifying the GitHub Pages deployment without repeating setup questions.
- `catalog.json` is the explicit publication allowlist. Never publish whole teaching
  directories or instructor-only material. Keep published URLs stable.
- `docs/` is generated by `python3 scripts/build.py`; edit its inputs, not the output.
- Verify changed course previews and downloads in the browser before pushing.
