01 / START HERE

Meet your files & folders

نبدأ من الأساسيات

الفايل هو ملف زي كود أو PDF. الفولدر مكان بتحط فيه ملفاتك وتجمعها مع بعض. جرّب الخطوات على الكمبيوتر وإنت بتقرأ من الموبايل.

  1. Click

    ضغطة واحدة بالزر الشمال بتختار الملف. ضغطتين ورا بعض بسرعة بتفتح الملف أو الفولدر.

  2. Right-click

    الزر اليمين بيظهر قائمة أوامر. على تاتش باد Mac تقدر تعمل Control + click عشان تفتحها.

  3. Find your files

    على Windows افتح File Explorer باختصار Windows + E. على Mac افتح Finder من الشريط اللي تحت. هتلاقي Documents وDownloads في القائمة الجانبية.

الصور هنا رسومات تعليمية مبسطة، مش لقطات شاشة فعلية. شكل القوائم ممكن يختلف حسب إصدار جهازك ولغة البرنامج.

02 / FILES

Create a folder

اعمل فولدر لشغلك

خلّي لكل كورس فولدر، وجواه فولدر لكل لاب. كده هتعرف تلاقي شغلك بعد ما تقفل البرنامج.

  1. Choose a place

    افتح Documents من File Explorer أو Finder.

  2. Windows

    اضغط بالزر اليمين في مساحة فاضية، واختار New → Folder. اكتب My labs واضغط Enter. الاختصار: Ctrl + Shift + N.

  3. Mac

    من القائمة فوق اختار File → New Folder، أو Shift + Command + N. اكتب الاسم واضغط Return.

  4. Make it yours

    افتح الفولدر الجديد بضغطتين، واعمل جواه فولدر للكورس، وبعدين Lab 01. الأسماء دي للتجربة؛ في التسليم استخدم الأسماء المطلوبة في الشيت.

المكان اللي ظاهر فوق النافذة هو عنوان الفولدر الحالي. افتكره عشان ترجع لنفس المكان وقت الحفظ.

03 / FILES

Copy, paste & move

انسخ ملف أو انقله

Copy بيعمل نسخة وبيسيب الأصل مكانه. Move بينقل الملف من المكان القديم للجديد.

  1. Copy

    اختار الملف بضغطة واحدة. على Windows اضغط Ctrl + C، وعلى Mac Command + C.

  2. Paste

    افتح فولدر تاني، واضغط Ctrl + V على Windows أو Command + V على Mac. دلوقتي فيه نسخة في كل مكان.

  3. Move instead

    على Windows: Ctrl + X، افتح المكان الجديد، ثم Ctrl + V. على Mac: Command + C ثم في المكان الجديد Option + Command + V.

  4. Check the result

    لو ظهر إن فيه ملف بنفس الاسم، اختار Cancel لو مش متأكد. افتح الملفين واتأكد من محتواهم قبل ما تستبدل واحد بالتاني.

اختصارات نسخ الملفات بتشتغل لما تكون محدد الملف في File Explorer أو Finder. لو جوه محرر الكود، هتنسخ النص المحدد.

04 / FILES

Rename & keep the extension

غيّر الاسم وسيب نوع الملف

في اسم زي hello.cpp، الجزء .cpp هو امتداد ملف C++. و.py لملف Python. تغيير الامتداد مش بيحوّل نوع الملف.

  1. Show extensions

    Windows 11: من View → Show → File name extensions. Windows 10: افتح تبويب View وعلّم على File name extensions.

  2. Windows

    اختار الملف، واضغط F2 أو بالزر اليمين اختار Rename. غيّر hello بس، وسيب .cpp زي ما هي، ثم Enter.

  3. Mac

    في Finder اختار الملف واضغط Return، عدّل الاسم ثم Return تاني. لإظهار الامتدادات: Finder → Settings → Advanced → Show all filename extensions؛ في الإصدارات الأقدم اسمها Preferences.

hello.cpp.txt مش ملف C++ بالامتداد المطلوب. ارجع للبرنامج واحفظه كملف C++، واتأكد من الاسم الكامل في فولدر الحفظ.

05 / STUDENT HUB

Download & find your materials

حمّل ملفات اللاب وافتحها

لينك الكورس بيجمع الأسابيع كلها. زرار Open بيفتح الملف أونلاين، وزرار Get أو Download بينزّله على جهازك.

  1. Choose your week

    افتح صفحة الكورس، واختار الأسبوع. افتح السلايدز أو الـ Guide من Open web، أو الشيت من Open PDF.

  2. Download

    حمّل ملف لوحده من Get HTML أو Get PDF حسب المتاح. لو عايز ملفات الأسبوع مع بعض اختار Download week ZIP.

  3. Find it

    افتح قائمة التنزيلات في المتصفح، واختار إظهار الملف في فولدره. غالبًا هتلاقيه في Downloads، إلا لو اخترت مكان تاني وقت التحميل.

  4. Open locally

    ملف PDF بيتفتح بقارئ PDF أو المتصفح. ملف HTML بيتفتح في المتصفح. لو نزلت ZIP، فكّه الأول بالطريقة اللي تحت، وسيب ملفات الأسبوع مع بعض عشان الروابط تفضل شغالة.

لو التحميل لسه شغال أو الملف حجمه صفر، استنى لحد ما يكتمل. السلايدز التفاعلية موجودة في نسخة HTML.

Save C++ from Dev-C++

احفظ ملف الكود نفسه

حفظ الكود مختلف عن تشغيله. المطلوب هنا إن يبقى عندك ملف .cpp تعرف مكانه وتقدر تفتحه تاني.

  1. New source file

    في Dev-C++ اختار File → New → Source File. لو الكود مفتوح عندك بالفعل، كمّل من الخطوة اللي بعدها.

  2. Save As

    اختار File → Save As. في نافذة الحفظ ادخل على Documents ثم فولدر اللاب اللي عملته.

  3. Name & save

    اكتب hello.cpp في File name، واختار نوع ملفات C++ source files (*.cpp) لو ظاهر، ثم اضغط Save.

  4. Check it

    بعد أي تعديل اضغط Ctrl + S. افتح فولدر اللاب واتأكد إن hello.cpp موجود. افتحه من File → Open في Dev-C++ وشوف إن آخر تعديل موجود.

الشرح ده لبرنامج Dev-C++ على Windows. على Mac استخدم محرر الكود المحدد في اللاب واحفظ بامتداد .cpp. ملف .exe الناتج من التشغيل أو صورة الشاشة مش بديل لملف الكود.

Save Python from PyCharm

اعرف ملف Python محفوظ فين

ملفات PyCharm بتكون جوه فولدر المشروع. البرنامج بيحفظ تلقائيًا في مواقف كتير، وتقدر تعمل حفظ يدوي كمان.

  1. Know the location

    لو بتعمل مشروع جديد من New Project، اختار مكانه في Location داخل فولدر شغلك. لو المشروع موجود، استخدم نفس المشروع.

  2. Create a Python file

    في قائمة Project على الشمال، اضغط بالزر اليمين على فولدر المشروع واختار New → Python File. اكتب hello، وهيتعمل hello.py.

  3. Save All

    بعد كتابة الكود اختار File → Save All. مع الاختصارات الافتراضية: Ctrl + S على Windows أو Command + S على Mac.

  4. Locate & check

    اضغط بالزر اليمين على hello.py في Project. دور على Open In → Explorer أو Finder حسب جهازك وإصدار البرنامج. أو افتح فولدر المشروع اللي اخترته في Location. اتأكد إن ملف .py موجود هناك.

للتسليم، خد ملفات .py المطلوبة حسب تعليمات الشيت. فولدر .venv بتاع بيئة Python مش هو كودك، ومش محتاج تضغطه مع الحل إلا لو مطلوب صراحة.

08 / WINDOWS / MAC

Make a ZIP

اجمع ملفاتك في ZIP واحد

ZIP بيجمع ملفات أو فولدر في ملف واحد سهل تبعته. اعمل فولدر فيه الملفات المطلوبة بس، واحفظ آخر تعديل قبل الضغط.

  1. Prepare

    لو هتضغط ملف واحد، اختاره مباشرة. لو عندك كذا ملف، حطهم في فولدر زي Lab 01، وارجع خطوة لبرّه الفولدر عشان تختاره.

  2. Windows 10

    اضغط بالزر اليمين على الفولدر، واختار Send to → Compressed (zipped) folder. هيتعمل ملف ZIP جنبه.

  3. Windows 11

    اختار Compress to ZIP file لو ظاهر، أو Show more options → Send to → Compressed (zipped) folder.

  4. Mac

    في Finder اعمل Control + click على الفولدر واختار Compress “Lab 01”. هتلاقي Lab 01.zip في نفس المكان.

Windows وMac فيهم ضغط ZIP من غير برنامج إضافي. لو عدّلت الكود بعد ما عملت ZIP، اعمل ZIP جديد عشان يحتوي على آخر نسخة.

09 / WINDOWS / MAC

Extract a ZIP

فك الضغط قبل ما تشتغل

فتح ZIP مش دايمًا معناه إنك فكّيته. اشتغل من الفولدر العادي اللي بيطلع بعد فك الضغط.

  1. Windows

    بالزر اليمين على ملف ZIP اختار Extract All…. اختار المكان اللي عايزه واضغط Extract.

  2. Mac

    اضغط مرتين على ملف .zip في Finder. هتلاقي الملفات أو الفولدر الناتج في نفس المكان.

  3. Open the extracted folder

    افتح الفولدر العادي الناتج، وبعدها افتح السلايدز أو الكود منه. خليك محافظ على ترتيب ملفات الأسبوع.

  4. If it fails

    اتأكد إن التحميل اكتمل. لو ظهر إن الأرشيف تالف، جرّب تنزّله تاني. لو صيغة الملف مش ZIP أو النظام مش قادر يفتحها، شوف خيار 7-Zip تحت.

سيب ZIP الأصلي موجود لحد ما تتأكد إن الملفات اتفكت وبتفتح. استخدم فولدر جديد للفك لو عندك نسخة قديمة عشان ما تستبدلش شغلك بالغلط.

10 / OPTIONAL · WINDOWS

Optional: install & use 7-Zip

لو محتاج برنامج لفك الضغط

جرّب طريقة النظام الأول. لو محتاج برنامج إضافي على Windows، استخدم 7-Zip من موقعه الرسمي. على Mac استخدم طريقة Finder اللي فوق لملفات ZIP.

  1. Choose the installer

    افتح لينك 7-Zip · Official download تحت. اعرف نوع جهازك من Settings → System → About → System type. اختار x64 لجهاز Intel/AMD بنظام 64-bit، أو ARM64 لجهاز ARM، أو x86 لنظام 32-bit.

  2. Install

    نزّل ملف .exe المناسب، افتحه من Downloads، واتبع خطوات Install ثم Close. على جهاز المعمل لو التثبيت محتاج صلاحيات، اطلب المساعدة من مسؤول المعمل.

  3. Create a ZIP

    بالزر اليمين على الفولدر اختار 7-Zip → Add to archive…؛ ممكن تحتاج Show more options في Windows 11. اختار Archive format: zip ثم OK.

  4. Extract

    بالزر اليمين على الأرشيف اختار 7-Zip → Extract files…، وحدد فولدر جديد ثم OK. لو قائمة 7-Zip مش ظاهرة، افتح 7-Zip File Manager من Start وحدد الملف واستخدم زر Extract.

اختار zip لو المطلوب ZIP؛ امتداد .7z مختلف. مش محتاج تثبّت WinRAR و7-Zip مع بعض عشان تمشي مع الشرح ده.

11 / FINAL CHECK

Before you send your work

مراجعة سريعة قبل التسليم

دقيقة مراجعة بتوفر عليك إنك تبعت ملف غلط أو نسخة قديمة.

  1. Save

    احفظ آخر تعديل، وافتح ملف الكود من مكانه واتأكد إن ده شغلك الحالي.

  2. Match the instructions

    راجع أسماء الملفات والفولدرات المطلوبة في الشيت، والامتدادات .cpp أو .py. الأسماء اللي في الشرح هنا للتجربة بس.

  3. Check the ZIP

    لو التسليم ZIP، فك نسخة منه في فولدر جديد وافتح الملفات اللي طلعت. اتأكد إنك حاطط ملفات الكود المطلوبة فعلًا، مش اختصار للفولدر أو ملفات التشغيل بس.

  4. Keep a copy

    احتفظ بنسخة من شغلك في مكان تقدر ترجع له، خصوصًا لو شغال على جهاز المعمل. اتبع طريقة وموعد التسليم المعلنين للكورس.

لو خطوة مش ماشية، ابعت اسم البرنامج، وصورة للمشكلة، والرسالة اللي ظهرت. كده نقدر نساعدك أسرع.

كده جاهز ترجع لملفات اللاب وتجرّب بنفسك.
