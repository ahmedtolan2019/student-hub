Chapter 1

One test chooses one block

Trace a two-way if/else and explain which statements run.

1.1 Read the test aloud

In this teaching example, a current above 16 A prints Overloaded; otherwise it prints Within rating. This is a simplified comparison exercise, not a model of a real circuit breaker.

> means greater than, < less than, >= and <= include equality. Use == to compare and != for not equal. One = assigns a value.

1.2 Braces group statements

The braces make a block. Without braces, an if controls only the next statement. A plain if can do nothing when false; an if/else executes exactly one of its two blocks.

Do not put a semicolon after if (current > 16). That would make an empty statement the controlled statement. A compiler may warn, but it can still produce an executable. Read warnings.

Chapter 2

A triangle needs every inequality

Use && for conditions that must all hold, before calculating an area.

2.1 A safe place for the formula

Q7 asks you to calculate an area only when the three edges form a triangle. Every pair must add to more than the remaining edge. && means all conditions must be true; || means at least one; ! reverses true and false.

2.2 Try the case that breaks your rule

3 4 5 gives area 6. 1 2 3 lies flat, so >= would wrongly accept it. 10 2 3 passes a+b>c, but fails another pair. One comparison is not enough.

Chapter 3

Convert first, then climb the BMI ladder

Turn Q18 into a plan and trace the first matching branch.

3.1 Five lines before code

Use the labels from the sheet as a programming exercise. Inputs here must be positive.

WANT
The BMI value in kg/m² and the word from the table.
HAVE
Weight in kg, height in cm; boundaries 18.5, 25 and 30.
CONVERT
heightM = heightCm / 100. The variable is double, so this is real division.
RELATE
bmi = weight / pow(heightM, 2), followed by the table from top to bottom.
CHECK
70 kg, 175 cm gives 22.8571, Normal. At 76.5625 kg and 175 cm, BMI is exactly 25, Overweight.

3.4 Why the second test has no lower bound

If execution reaches bmi < 25, the first test bmi < 18.5 already failed. The lower bound is established by the path. Once a branch runs, the later tests are not evaluated.

Test below, at and above the boundary

Choose inputs that expose a wrong comparison, then plan a new decision.

4.1 Q14 includes the circle edge

4.2 Your turn: a cable decision

This extra exercise uses a given resistance of 7.41 Ω/km per conductor, a 16 A current, a 220 V supply and a 5% budget. Treat these as exercise assumptions: two conductors, a resistive load, and reactance ignored.

In your notebook, write WANT, HAVE, CONVERT, RELATE and CHECK before opening the answer. Read the one-way length L in meters; print the drop in volts and whether it is within the given budget.

Compare your plan

Chapter 5

Finish the selection questions

Choose a decision structure and a test for each remaining question.

Lab priority: Q7, Q18, then Q14 alone. Q11 is the extension. Use these routes for the remaining questions; write and test your own files. Keep Q1-Q6, Q8 and Q12 from week 2.

Q9 · three discriminant cases

Assume a is nonzero for a quadratic. Compute d = b*b - 4*a*c. For d > 0, print (-b+sqrt(d))/(2*a) and (-b-sqrt(d))/(2*a); for d == 0, print -b/(2*a); otherwise print exactly "The equation has no real roots." Do not calculate sqrt(d) in the negative case. Use <cmath>.

Test: 1 -3 2 → roots 2 and 1; 1 2 1 → -1; 1 2 5 → no real roots.

Q10 · three separate comparisons

Read integers a, b, c. If a<b, exchange them using temp=a; a=b; b=temp;. Then if a<c, exchange a and c. Finally if b<c, exchange b and c. These are three independent if statements: test all three, although a swap only runs when its test is true.

Test: 1 2 3 → 3 2 1; 3 2 1 → unchanged; 2 2 1 → 2 2 1.

Q11 · validity, then triangle type

Use Q7's validity test first. In the valid branch: if a==b && b==c, Equilateral; else if a==b || a==c || b==c, Isosceles; else Scalene. Test equilateral first because it also satisfies the two-equal test.

Test: 5 5 5 → Equilateral; 5 5 8 → Isosceles; 3 4 5 → Scalene; 1 2 3 → invalid.

Q13 · a valid three-digit integer

Test n>=100 && n<=999. In the valid branch, hundreds=n/100; tens=(n/10)%10; units=n%10; print their sum. Otherwise print invalid.

Test: 456 → 15; 100 → 1; 999 → 27; 99 and 1000 → invalid.

Q15 · check containment before overlap

Find d between the centers using the Q4 distance formula. The supplied hint tests d<=fabs(r1-r2), then d<=r1+r2, then neither. Its first condition detects containment in either direction. To say specifically "circle2 is inside circle1", the directional condition is d+r2<=r1. Ask the TA which interpretation the professor wants before final submission.

Test: 0 0 5 / 0 0 2 → circle2 inside; 0 0 5 / 6 0 2 → overlap; 0 0 5 / 10 0 2 → neither. Reversing the radii exposes the hint's ambiguity.

Q16 · clock arithmetic, then AM/PM

Include <ctime>. Obtain seconds from time(0). second=totalSeconds%60; minute=(totalSeconds/60)%60; hour=(totalSeconds/3600+offset)%24. Read the whole-hour GMT offset. If hour==0, display 12 AM; else if hour<12, display hour AM; else if hour==12, display 12 PM; otherwise display hour-12 PM. Minutes and seconds remain unchanged.

Test: Test the conversion with fixed hour values: 0 → 12 AM; 11 → 11 AM; 12 → 12 PM; 23 → 11 PM. Live seconds change on every run.

Q17 · print the equation in pieces

For x1!=x2, calculate m=(y2-y1)/(x2-x1) and b=y1-m*x1 in double. Start with "y = ". If m!=1, print m; then print "x". If b>0 print " + " and b; else if b<0 print " - " and -b; if b==0 print nothing. The sheet's slope formula assumes a nonvertical line.

Test: 0 3 / 2 5 → y = x + 3; 0 -3 / 1 -1 → y = 2x - 3; 0 0 / 1 1 → y = x.

Chapter 6

Name it, save it: the professor's rules

After this chapter you can make the sheet folder and every question file with exactly the names the professor specifies, on a lab PC, without help.

6.1Five rules to check before submission

Follow the professor's file and folder naming instructions for every sheet. The rules, from the note the professor sent to every student:

  1. No Arabic and no spaces in any file or folder name. English letters, digits and underscores only.
  2. One folder per sheet, named XXX_Sheet_N. XXX is your number on the class list, always three digits.
  3. One file per question, named Q_SSQQ.cpp: two digits for the sheet, two for the question. Underscores, never dashes.
  4. Delete the .exe files before you send. Dev-C++ makes one next to every .cpp you run.
  5. Archive the whole folder into one file with the folder's name, and upload it at the link the professor announces. ZIP and RAR are both allowed; this guide uses Windows ZIP.

Consistent names let the marker identify your class-list number, sheet and question without opening each program. Do not substitute your university ID for your number on the class list.
