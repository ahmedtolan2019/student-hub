القيمة والاسم ونوع البيانات

ابدأ بـx = 3. الاسم يرتبط بقيمة. int للأعداد الصحيحة، float للقيم التي قد تحتوي جزءًا كسريًا، str للنص، bool للحكم True أو False. = إسناد، و== مقارنة.

1x = 3
2y = 2.5
3print(x + y)
4print(x == 3)

شرح السطور واحدة واحدة
  1. x = 3

    x يأخذ العدد الصحيح 3.

  2. y = 2.5

    y يأخذ قيمة float.

  3. print(x + y)

    نجمع القيمتين ثم نعرض الناتج.

  4. print(x == 3)

    نقارن قيمة x بالعدد 3؛ الناتج Boolean.

5.5

قراءة المدخلات وإظهارها

input يرجع نصًا؛ حوّله بالنوع المطلوب. استخدم int لعدد الحدود وfloat لقيمة مثل a أوx. اكتب المدخلات أرقامًا صالحة؛ فحص النصوص غير الرقمية خارج تركيز هذا الشيت.

1n = int(input("Number of terms: "))
2a = float(input("First term: "))
3print(f"n = {n}, a = {a:.2f}")

شرح السطور واحدة واحدة
  1. n = int(input("Number of terms: "))

    نقرأ نصًا ثم نحوله إلى int.

  2. a = float(input("First term: "))

    نقرأ أول حد ونحوله إلى float.

  3. print(f"n = {n}, a = {a:.2f}")

    f يسمح بإدخال القيم بين الأقواس المعقوفة؛ :.2f يعرض رقمين بعد العلامة العشرية.

العوامل التي سنحتاجها

** للأس، / للقسمة، // لقسمة أرضية، % للباقي. مع أعداد الخانات الموجبة، // 10 يحذف الأخيرة و% 10 يأخذها. لا تستخدم ^ بدل **.

1print(3 ** 3)
2print(7 / 2)
3print(7 // 2)
4print(7 % 2)
5print(4827 // 10, 4827 % 10)

شرح السطور واحدة واحدة
  1. print(3 ** 3)

    3 مرفوعة للقوة 3.

  2. print(7 / 2)

    قسمة تعطي قيمة كسرية.

  3. print(7 // 2)

    قسمة أرضية تعطي 3 في هذا المثال الموجب.

  4. print(7 % 2)

    باقي القسمة يساوي 1.

  5. print(4827 // 10, 4827 % 10)

    ناتج القسمة 482 والباقي 7.

1total = 0
2for i in range(1, 5):
3 total += i
4print(total)

    ابدأ مجموعًا فارغًا بصفر.

  2. for i in range(1, 5):

    القيم هي 1 ثم 2 ثم 3 ثم 4.

    داخل الحلقة: أضف i للمجموع الحالي.

  4. print(total)

    خارج الحلقة: اعرض المجموع النهائي مرة واحدة.

while: شرط وتقدم وتوقف

while تعيد فحص الشرط قبل كل دورة. يجب أن يتغير شيء يقربها من التوقف. المثال يجمع خانات عدد موجب.

1number = 4827
2total = 0
3while number > 0:
4 total += number % 10
5 number //= 10
6print(total)

    مثال ثابت للتتبع.

  2. total = 0

    اجمع الخانات بدءًا من صفر.

  3. while number > 0:

    استمر طالما توجد خانات.

  4. total += number % 10

    خذ آخر خانة وأضفها.

  5. number //= 10

    احذف آخر خانة حتى تتقدم الحلقة.

  6. print(total)

    بعد انتهاء الحلقة اعرض المجموع.

def ثم call ثم return

الدالة جزء مسمى من البرنامج له مدخلات ونتيجة. parameter اسم داخل التعريف، وargument القيمة المرسلة عند الاستدعاء. التعريف وحده لا يحسب الناتج.

1def cube(num):
2 result = num ** 3
3 return result
4
5answer = cube(3)
6print(answer)

شرح السطور واحدة واحدة
  1. def cube(num):

    عرّف cube باسم مدخل num؛ النقطتان تبدأان جسمها.

  2. result = num ** 3

    احسب المكعب عندما تُستدعى الدالة.

  3. return result

    ارجع إلى مكان الاستدعاء بهذه القيمة.

  4. answer = cube(3)

    استدعِ الدالة بالقيمة 3 واستلم الناتج في answer.

  5. print(answer)

    اعرض القيمة التي استلمتها.

return ليست print

print لها أثر ظاهر على الشاشة وترجع None. return تسلّم قيمة للمستدعي وتنهي الاستدعاء. يمكن للمستدعي تخزين القيمة أو استعمالها في حساب جديد.

1def twice(x):
2 return x * 2
3
4a = twice(3)
5print(a + 1)

شرح السطور واحدة واحدة
  1. def twice(x):

    عرّف عملية بمدخل واحد.

  2. return x * 2

    أعد الناتج بدل طباعته فقط.

  3. a = twice(3)

    استلم الناتج العددي 6.

  4. print(a + 1)

    استعمل القيمة في حساب آخر ثم اطبع 7.

أكثر من قيمة، ونطاق الأسماء

إعادة الإسناد داخل الدالة تغيّر الاسم المحلي. لو المطلوب تغيير قيمتين في المستدعي، أعدهما واستلمهما. الجانب اليمين من الإسناد المتعدد يُحسب قبل إسناد الجانب اليسار.

1def swap(a, b):
2 return b, a
3
4x = 8
5y = 3
6x, y = swap(x, y)
7print(x, y)

شرح السطور واحدة واحدة
  1. def swap(a, b):

    اسمان محليان يستقبلان قيمتي x وy.

  2. return b, a

    أعد tuple من القيمتين بترتيب معكوس.

  3. x = 8

    اسم في البرنامج الرئيسي.

  4. y = 3

    اسم ثانٍ في البرنامج الرئيسي.

  5. x, y = swap(x, y)

    استلم القيمتين الراجعتين في الاسمين.

  6. print(x, y)

    النتيجة 3 ثم 8.

Defaults والمكتبات

القيمة الافتراضية تعوّض argument غير مرسل. import يتيح أسماء من مكتبة. في الشيت نستخدم math.pow وmath.sqrt وrandom.randint؛ النقطة تربط اسم المكتبة باسم الدالة.

1import math
2
3def add(a=0, b=0):
4 return a + b
5
6print(add(5))
7print(math.sqrt(49))

شرح السطور واحدة واحدة
  1. import math

    أتح أسماء مكتبة math.

  2. def add(a=0, b=0):

    اجعل المدخلين اختياريين بقيمة صفر.

  3. return a + b

    أعد مجموعهما.

  4. print(add(5))

    استُقبل a = 5، واستُخدم b = 0.

  5. print(math.sqrt(49))

    sqrt تحسب الجذر التربيعي وتعيد 7.0.

السؤالالمتطلبات
1input → float → def والـindentation → parameter وargument → return → استدعاء داخل إسناد → f-string.
2عامل + و- و*؛ دالة بوسيطين؛ ترتيب arguments؛ استدعاء متداخل داخل print.
3الإسناد ينقل قيمة من اليمين لليسار؛ متغير مؤقت؛ نطاق محلي؛ return لقيمتين؛ tuple unpacking.
4قيمة Boolean؛ if؛ <=؛ %؛ ==؛ for وrange؛ math.sqrt؛ int؛ return مبكر.
5استدعاء داخل شرط؛ range(lower, upper + 1)؛ print مع end؛ الفصل بين المرشح والقاسم.
6مجال المدخلات؛ or؛ for من 2 إلى n شاملًا؛ *=؛ return خارج الحلقة.
7function بثلاثة parameters؛ range(n)؛ ضرب قبل جمع؛ total = 0؛ +=.
8الأس **؛ الأقواس؛ range(n)؛ الفرق بين common difference وcommon ratio.
9import random؛ randint؛ while؛ %؛ //؛ //=؛ قيمة محلية لا تمحو عدد البرنامج الرئيسي.
10range(1, n + 1, 2)؛ دالة تستدعي دالة؛ /؛ **؛ f-string مع :.6f؛ تحقق من العدد الفردي.
11print مع end=""؛ f-string؛ شرط i < n لمنع + أخيرة؛ حلقة تبدأ من 1؛ return مقابل None.
12def calculate_sum(arg1=0, arg2=0, arg3=0, arg4=0)؛ positional arguments؛ keyword arguments كامتداد بسيط.
