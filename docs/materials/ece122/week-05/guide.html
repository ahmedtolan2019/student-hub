Default arguments: القيم المحذوفة لها بديل
المطلوب إيه؟
عرّف دالة تجمع أربع قيم، وكل parameter قيمته الافتراضية صفر. جرّب استدعاء الدالة بأربع قيم، وبعض القيم، وقيمة واحدة، وبدون قيم.
الفكرة قبل الكود
القيمة الافتراضية تُستخدم عندما لا يرسل الاستدعاء argument لهذا parameter. لا تُضاف صفرًا فوق القيمة المرسلة، ولا تُلزم المستدعي بكتابة أربعة arguments كل مرة.

calculate_sum(5,15)5150 default0 default20
calculate_sum(100)1000 default0 default0 default100
calculate_sum()0 default0 default0 default0 default0
نتتبع مثالًا
(10,20,30,40) → 100؛ (5,15) → 20؛ (100) → 100؛ () → 0؛ وبالاسم arg3=7 → 7.
