count = 0

voltage = 12.5
label = "Voltage"

input, int and float

هتحتاجه في Q1-Q4، Q6-Q9، Q12-Q15

input بتوقف البرنامج لحد ما المستخدم يكتب ويضغط Enter، وبترجّع نص. لو محتاج حساب عددي، نحول النص إلى int أو float.

name = input("Enter your name: ")
count = int(input("Enter a whole number: "))
voltage = float(input("Enter voltage: "))
print(name, count, voltage)
  • int(input(...)) مناسب لعدد صحيح. اكتب 3، مش 3.5.
  • float(input(...)) يقبل قيمة زي 3.5، ويقبل 3 كمان.
  • كل input هنا بيقرأ قيمة واحدة في سطر. ما تكتبش عدة أعداد مفصولة بفواصل إلا لو الكود طالب ده.
  • الكود الحالي للدكتور بيستخدم int وfloat. استخدمنا نفس الأسلوب هنا؛ مش محتاجين eval عشان نقرأ رقمًا واحدًا.

تتبّع متوقع

Keyboard "3.5" → input → str
float("3.5") → 3.5
جرّب تجاوب قبل ما تفتح

هل input لوحدها بتحوّل "5" تلقائيًا إلى العدد 5؟

شوف الإجابة

لأ. "5" نص. int أو float هما اللي بيعملوا التحويل العددي.

PYTHON BASICS · 04

عمليات هنحتاجها طول الشيت
Arithmetic operators

هتحتاجه في كل الأسئلة، خصوصًا Q4-Q15

اكتب الأقواس لما تحتاج تحدد مجموعة تتحسب مع بعض. ** للأس، و% للباقي، و// للقسمة الأرضية. مع عدد صحيح غير سالب، //10 بتشيل آخر رقم.

a = 17
print(a / 5)
print(a // 5)
print(a % 5)
print(2 ** 3)
print(1 / (2 * 3))
  • 17/5 ناتجها المتوقع 3.4، و17//5 ناتجها 3، والباقي 17%5 يساوي 2.
  • 2**3 معناها 2×2×2. الرمز ^ مش للأس.
  • 1/(2*3) مختلفة عن 1/2*3. الأقواس بتحدد المقام كله.
  • // بتقرب لتحت، مش ناحية الصفر. -1//10 يساوي -1؛ عشان كده بنستخدم abs قبل تقطيع الأرقام.

تتبّع متوقع

17 = 5 × 3 + 2
17 // 5 = 3
17 % 5 = 2
جرّب تجاوب قبل ما تفتح

إيه الاختبار المناسب لمعرفة هل n زوجي؟

شوف الإجابة

n % 2 == 0، لأن الزوجي بيتقسم على 2 من غير باقي.

PYTHON BASICS · 05

نسأل سؤالًا ونختار فرعًا
Comparisons and if

هتحتاجه في Q2-Q4، Q7-Q8، Q13-Q15

المقارنة بتطلع True أو False. if بتنفذ كتلة لما الشرط صحيح، وelif بتسأل سؤالًا تاني، وelse بتغطي الحالات الباقية.

n = int(input("Enter an integer: "))
if n > 0:
    print("Positive")
elif n < 0:
    print("Negative")
else:
    print("Zero")
  • == للسؤال عن التساوي. = لتخزين قيمة. != للسؤال عن الاختلاف.
  • الرموز < و<= و> و>= بتفرق في دخول الحد نفسه.
  • بعد if وelif وelse فيه نقطتان :. السطور التابعة داخلة 4 مسافات.
  • and محتاجة الشرطين مع بعض، وor يكفيها واحد. مثال: a==0 and b==0 يسأل هل العددان صفر.

تتبّع متوقع

condition → True: execute this block
condition → False: try the next branch
جرّب تجاوب قبل ما تفتح

لو n=0، هل الفرع n>0 هيتنفذ؟

شوف الإجابة

لأ. ولا n<0 كمان. هنوصل إلى else.

PYTHON BASICS · 06

while: ابدأ، اختبر، نفّذ، حدّث
The while loop

هتحتاجه في Q1-Q9، Q13-Q14

while بتكرر مجموعة سطور طول ما الشرط صحيح. الشرط بيتفحص قبل أول دورة وقبل كل دورة بعدها. ممكن الجسم ما يتنفذش نهائيًا.

i = 1
while i <= 3:
    print(i)
    i = i + 1
print("Done")
  • البداية i=1 تحصل مرة واحدة قبل الحلقة.
  • الشرط i<=3 يتفحص كل مرة، والجسم فيه الطباعة والتحديث.
  • لما i تبقى 4، الشرط يبقى False ونكمل بعد الحلقة.
  • لو نسيت التحديث، الشرط ممكن يفضل صحيحًا للأبد. أوقف البرنامج من زر Stop في نافذة Run.

تتبّع متوقع

i=1 → print 1 → i=2
i=2 → print 2 → i=3
i=3 → print 3 → i=4
i=4 → stop → Done
جرّب تجاوب قبل ما تفتح

لو بدأنا i=4 في نفس المثال، كام مرة هيتنفذ print(i)؟

شوف الإجابة

صفر مرات، لأن أول اختبار للشرط False.

PYTHON BASICS · 07

عداد ومجموع وحاصل ضرب
Counters and accumulators

هتحتاجه في Q1-Q4، Q6-Q7، Q9-Q13

العداد بيعد مرات. المجموع بيجمع قيم. حاصل الضرب بيضرب قيم. كل واحد له وظيفة وبداية مختلفة.

i = 1
total = 0
product = 1
while i <= 3:
    total += i
    product *= i
    i += 1
print(total, product)
  • total يبدأ بصفر لأن إضافة صفر لا تغيّر القيمة.
  • product يبدأ بواحد لأن الضرب في واحد لا يغيّر القيمة.
  • total += i هي نفس total = total + i. وproduct *= i نفس الضرب والإسناد.
  • لو عايز تجمع عبر دورات الحلقة، صفّر المجموع قبلها، مش في جسمها.

تتبّع متوقع

i      total      product
1        1           1
2        3           2
3        6           6
جرّب تجاوب قبل ما تفتح

لو نقلنا total=0 لجوه الحلقة قبل الجمع، هيحتفظ بالمجموع السابق؟

شوف الإجابة

لأ. كل دورة هتبدأ من صفر، وفي الآخر هيبقى آخر عدد فقط.

نكرر لحد إشارة توقف
Sentinel values

هتحتاجه في Q3

لو عدد مرات الإدخال مش معروف، نستخدم قيمة متفق عليها للتوقف. في المثال الصفر يوقف الإدخال، ومش بندخّله في المجموع.

total = 0
n = int(input("Enter a number, 0 to stop: "))
while n != 0:
    total += n
    n = int(input("Enter a number, 0 to stop: "))
print(total)
  • أول input قبل الحلقة يجهّز القيمة اللي هنسأل عنها.
  • القراءة التانية جوه الحلقة بتجيب القيمة التالية.
  • ابدأ بصفر وجرب التتبع: جسم الحلقة مش هيتنفذ.
  • في Q3 هنستبدل total بمجموعين، ونستخدم if للتصنيف.

تتبّع متوقع

Inputs: 4, -1, 0
total: 0 → 4 → 3
0 ends the loop
جرّب تجاوب قبل ما تفتح

هل لازم نعرف عدد القيم قبل البداية؟

شوف الإجابة

PYTHON BASICS · 09

نفك العدد رقمًا رقمًا
Digit extraction

هتحتاجه في Q6-Q8

مع num غير سالب، %10 تستخرج آخر رقم، و//10 تحذف آخر رقم. العمليات دي بتتحرك من يمين العدد لشماله.

num = abs(int(input("Enter an integer: ")))
while num != 0:
    digit = num % 10
    print(digit)
    num = num // 10
  • لو num=305، آخر رقم 5، وبعد حذفه يتبقى 30.
  • الرقم التالي صفر، ولازم يمر في التتبع زي أي رقم.
  • abs بتفصل الإشارة عن الأرقام وتمنع مشكلة استمرار القسمة الأرضية مع السالب.
  • الإدخال صفر محتاج تفكير منفصل: الحلقة دي لا تطبع رقمًا، لأن الشرط False من البداية.

تتبّع متوقع

num     digit     next num
305       5          30
 30       0           3
  3       3           0
جرّب تجاوب قبل ما تفتح

مع 305، ترتيب الأرقام المطبوعة هيكون إيه؟

شوف الإجابة

5 ثم 0 ثم 3. الاستخراج بيبدأ من اليمين.

for وrange بالحدود الصح
for and range

هتحتاجه في Q10-Q12، Q15

for مناسبة لما القيم أو عدد الدورات معروفين. range(start, stop, step) تولد أعدادًا صحيحة تبدأ من start وتقف قبل stop، وتتحرك بمقدار step.

for i in range(4):
    print(i)

for denominator in range(5, 18, 4):
    print(denominator)
  • range(4): القيم 0، 1، 2، 3. البداية الافتراضية صفر والخطوة 1.
  • range(1,4): القيم 1، 2، 3. حد التوقف 4 مش داخل.
  • range(5,18,4): القيم 5، 9، 13، 17.
  • لو عايز 1 إلى n شاملًا بخطوة موجبة 1، اكتب range(1,n+1).

تتبّع متوقع

start = 5
step = 4
5 → 9 → 13 → 17
next 21 is outside stop=18
جرّب تجاوب قبل ما تفتح

range(1,3) فيها كام قيمة؟

شوف الإجابة

قيمتين: 1 و2. الرقم 3 حد توقف.

المضروب بيتبني بالتدريج
Building a factorial

هتحتاجه في Q2، Q9، Q12

الرمز ! هنا معناه factorial. نضرب الأعداد من 1 إلى n. الرقم التالي بيضيف عاملًا واحدًا للمضروب السابق، فمش لازم نعيد الحساب كل مرة.

fact = 1
for i in range(1, 5):
    fact *= i
    print(i, fact)
  • بعد i=1، fact فيها 1!. بعد i=2، فيها 2!، وهكذا.
  • 0!=1، وده متوافق مع بداية fact=1 لو مفيش عوامل هتتضرب.
  • fact متغير نتيجة. i هو رقم العامل الحالي.
  • في Q9 بنستفيد من fact بعد كل تحديث عشان نضيف حدًا جديدًا.

تتبّع متوقع

1! = 1
2! = 1 × 2 = 2
3! = 2 × 3 = 6
4! = 6 × 4 = 24
جرّب تجاوب قبل ما تفتح

لو fact حاليًا فيها 3!، إزاي نحصل على 4!؟

شوف الإجابة

نضرب fact في 4، فتكون 24.

Nested loops

هتحتاجه في Q11-Q12

for group in range(1, 3):
    total = 0
    for item in range(1, 4):
        total += item
    print(group, total)
  • group تاخد 1 ثم 2. لكل واحدة، item تمر على 1 و2 و3.
  • total=0 جوه الخارجية، فكل مجموعة لها مجموع مستقل.
  • print بعد الداخلية وجوه الخارجية، فهتطبع مرة لكل مجموعة.
  • في Q11، المجموعة هي قيمة n. في Q12، المجموعة هي الحد صاحب الأس i.

تتبّع متوقع

group 1: total 0 → 1 → 3 → 6
group 2: total 0 → 1 → 3 → 6
جرّب تجاوب قبل ما تفتح

كام مرة يتنفذ total += item هنا؟

شوف الإجابة

من شكل المتسلسلة إلى حلقة
Term, index and total

هتحتاجه في Q9-Q12

افصل بين رقم الحد index، وقيمة الحد term، والمجموع total. اكتب أول حدين وآخر حد على ورقة قبل ما تختار بداية الحلقة ونهايتها.

total = 0.0
for i in range(1, 4):
    term = 1.0 / (i * i)
    total += term
print(total)
  • المثال يجمع 1/1² و1/2² و1/3². i رقم الحد، مش قيمة الحد.
  • الجمع يبدأ بصفر. لو السؤال حاصل ضرب، نبدأ بواحد ونضرب.
  • اسأل عن البسط والمقام كل واحد لوحده. 1/i! مختلفة عن i/i!.
  • من 0 إلى 15 فيه 16 حدًا. من 1 إلى 15 فيه 15 حدًا.

تتبّع متوقع

i=1 → term=1
i=2 → term=1/4
i=3 → term=1/9
total accumulates the terms
جرّب تجاوب قبل ما تفتح

في المثال، هل term بتساوي i؟

شوف الإجابة

لأ. term=1/(i*i). مثلًا عند i=2، الحد 1/4.

PYTHON BASICS · 14

نعرض العدد بطريقة مفهومة
print, format and f-strings

هتحتاجه في Q1، Q9-Q12، Q15

التنسيق بيغير شكل العرض، مش القيمة الأصلية. محتاجين أحيانًا عددًا محددًا من الأرقام بعد العلامة العشرية، أو صيغة علمية لعدد صغير جدًا.

value = 2.5
print("Value =", value)
print(format(value, ".3f"))
print(f"Value = {value:.3f}")
small = 0.0000123
print(format(small, ".2e"))
  • .3f تعرض 3 أرقام بعد العلامة العشرية، فـ2.5 تظهر 2.500.
  • f قبل النص تسمح بوضع متغير أو تعبير جوه {}.
  • .2e تعرض مثلًا 1.23e-05، وده معناه 1.23 مضروبة في 10 أس -5.
  • في >10.6f، الرقم 10 عرض أدنى والمحاذاة لليمين، و6 عدد الأرقام بعد العلامة العشرية.

تتبّع متوقع

2.5 → .3f → 2.500
0.0000123 → .2e → 1.23e-05

math: جذر وزوايا
sqrt, radians, sin and cos

هتحتاجه في Q11، Q15

import math يخلينا نستخدم دوال الرياضيات. math.sqrt للجذر التربيعي، وmath.sin وmath.cos للزوايا بالراديان. لو الزاوية بالدرجات، نحولها أولًا.

import math
root = math.sqrt(9)
angle = math.radians(30)
radius = 2
x = radius * math.cos(angle)
y = radius * math.sin(angle)
print(root)
print(format(x, ".2f"), format(y, ".2f"))
  • رياضيا، إحداثيات نقطة على دائرة مركزها الأصل: x=r*cos(angle)، وy=r*sin(angle).
  • 90 درجة تساوي pi/2 راديان، وتشير لأعلى من محور x الموجب.
  • في Q15 هنحدد 5 زوايا، ونحسب زوج إحداثيات لكل واحدة.
  • الأعداد العشرية في الكمبيوتر تقريبية؛ نتائج قريبة جدًا من صفر ممكن تظهر بإشارة سالبة عند التنسيق.

تتبّع متوقع

degrees → math.radians → radians
x = r × cos(angle)
y = r × sin(angle)
جرّب تجاوب قبل ما تفتح

هل math.sin(30) معناها sin لزاوية 30 درجة؟

شوف الإجابة

لأ. معناها 30 راديان. للدرجات اكتب math.sin(math.radians(30)).

هتحتاجه في Q13-Q14

a%b==0 معناها b قاسم لـa، بشرط b مش صفر. نفس عملية الباقي بتساعدنا نختبر الأولية ونحسب أكبر قاسم مشترك.

a = 20
b = 12
remainder = a % b
a = b
b = remainder
print(a, b)
  • المثال يحوّل الزوج 20 و12 إلى 12 و8. حسبنا الباقي قبل تغيير العددين.
  • لو كتبنا a=b الأول وبعدين a%b، هنكون استخدمنا قيمًا اتغيرت.
  • Q13 بيسأل: هل فيه قاسم إضافي غير 1 والعدد نفسه؟ لازم نبدأ بعد التأكد إن العدد أكبر من 1.
  • Q14 يكرر تحديث إقليدس طول ما المقسوم عليه غير صفر.

تتبّع متوقع

old pair: (20, 12)
remainder = 20 % 12 = 8
new pair: (12, 8)
جرّب تجاوب قبل ما تفتح

إيه فائدة remainder بدل تحديث a وb فورًا؟

بتحفظ نتيجة الحساب بالقيم القديمة، قبل ما نستبدل واحدة منهم.
