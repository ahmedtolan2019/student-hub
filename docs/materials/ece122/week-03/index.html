قبل ما تبدأ

  • لو فتحت ZIP، فك الضغط الأول، وبعدها افتح index.html. كل الملفات تشتغل من غير إنترنت.
  • احفظ محاولتك من «حفظ تقدّمي»، ونزّل JSON backup. الحفظ يعتمد على نفس المتصفح ومكان الملفات.
  • الأمثلة المسجلة اتشغّلت على Python 3.14.6. المتصفح يعرض التسجيلات ولا يشغّل كود Python جديد. شغّل ملف .py على جهازك لتجرب مدخلاتك.
  • ملاحظات الاختلاف بين الشيت والكود المرجعي ظاهرة عند السؤال. رسوم الـGuide تعليمية، وصورة السؤال هي الأصل.
