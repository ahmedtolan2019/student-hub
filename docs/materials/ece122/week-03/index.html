كل سؤال في الـGuide ماشي كده

  1. السؤال بيقول إيه: كلام الشيت ← معناه ← اسمه في Python ← وحدته، والجزء متعلّم في السؤال الأصلي.
  2. توقّع الأول (اختياري): سؤال صغير قبل الشرح.
  3. على السبورة: رسم من المثال نفسه، وكل خطوة بتجاوب سؤال واحد وبتزوّد سطر.
  4. خطتك: WANT / HAVE / CONVERT / RELATE / CHECK، وبعدين تقارن سطر سطر.
  5. من الخطة للكود: جزء جزء، وكل جزء جاي من سطر في الخطة.
  6. تشغيل مسجّل: الذاكرة قبل وبعد كل سطر، والأسئلة اللي اتسألت.
  7. لوحدك: مدخلات جديدة، وشرحك أنت.
