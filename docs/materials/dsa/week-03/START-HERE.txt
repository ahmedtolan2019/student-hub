   no installed interpreter appears. No download or package installation is needed.

   Use the same file for your find_order and, optionally, cancel_order/find_sorted.
   All task requirements and test calls are on the whiteboard. No import is needed.

LESSON ROUTE
Memory and contiguous reference slots, list syntax and functions, storage growth,
list operations, search specification, pseudocode, trace and correctness, time and
auxiliary space, Python implementation, debugging, tests, then independent lookup.
Core: boards 1–34, 90 minutes. Stop at the Exit check.
Optional cancellation challenge: boards 35–36, 10 additional minutes.
Optional binary-search extension: boards 37–49, 35 additional minutes.
After-lab references: boards 50–52.
The memory capacities and addresses are illustrations, not measured allocations.

ALGORITHM DESIGN
State the specification: inputs, output, assumptions and mutation. Write pseudocode,
trace an example, explain correctness and termination, and analyze time and auxiliary
space. Then translate to Python and test. Write design notes on paper or as comments
beginning with #. Pseudocode itself is not runnable Python.

قبل التنفيذ حدّد المواصفات، واكتب pseudocode واتتبّع مثال، وفسّر صحة النتيجة
وليه الخوارزمية بتقف، وحلّل الوقت والمساحة الإضافية. بعدها نفّذ واختبر.
اكتب التصميم على ورقة أو comments بتبدأ بـ#؛ الـpseudocode مش كود Python.
