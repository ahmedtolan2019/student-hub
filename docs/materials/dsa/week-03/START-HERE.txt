ALGORITHM DESIGN
Before implementing, state the specification (inputs, output, assumptions and
mutation). Write pseudocode, trace an example, explain correctness and why it
stops, and analyze time and auxiliary space. Then translate to Python and test.
Pseudocode symbols are explained on the whiteboard; do not run pseudocode in
PyCharm. Practice files contain a design template to complete.
