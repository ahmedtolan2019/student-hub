Follow the boards in order: list basics and function calls, list operations,
search specification and pseudocode, trace and correctness, time/space analysis,
then Python implementation, tests and practice. Stop at board 31 for the core lab.

Boards 45–48 are reference material. 01_list_operations.py is for the list lesson;
00_ready.py only checks that Python runs.

No pip install, NumPy or internet is needed. Public source links need internet.
No deadline or submission method is defined by this pack; use your instructor's
actual class instructions.

ALGORITHM DESIGN
Before implementing, state the specification (inputs, output, assumptions and
mutation). Write pseudocode, trace an example, explain correctness and why it
stops, and analyze time and auxiliary space. Then translate to Python and test.
Pseudocode symbols are explained on the whiteboard; do not run pseudocode in
PyCharm. Practice files contain a design template to complete.
