   The numbered SQL files follow the video. BookCopies.csv contains 36 fictional

   DB1-Task-1-College-Equipment-Database.pdf is the English academic handout.

   Write your SQL in Lab03-Equipment-starter.sql. Equipment.csv has the five rows.

environment provided for your class. Run each INSERT once. Keep existing
databases and ask your instructor if a requested database name already exists.
