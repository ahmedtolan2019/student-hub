Task 1: College Equipment Database

نسخة PDF بالإنجليزي

مسؤول المعامل محتاج يسجل الأجهزة، ويعرف الأجهزة المتاحة للاستخدام ومكان كل جهاز. اعمل قاعدة بيانات صغيرة تساعده يجاوب على السؤال ده.

كل صف هيمثل جهاز واحد فعلي. ممكن جهازين يبقوا Laptop، لكن كل واحد ليه رقم مختلف وحالة مختلفة.

الجدول اللي هتعمله

اسم قاعدة البيانات CollegeEquipment، واسم الجدول Equipment.

ColumnData typeConstraint
EquipmentIdINTPRIMARY KEY
EquipmentNameNVARCHAR(60)NOT NULL
RoomNVARCHAR(10)NOT NULL
IsAvailableBITNOT NULL

IsAvailable = 1 يعني الجهاز متاح، و0 يعني مش متاح دلوقتي.

المطلوب بالترتيب

  1. اعمل قاعدة البيانات بـCREATE DATABASE.
  2. اختارها بـUSE.
  3. اعمل جدول Equipment بالأعمدة والأنواع والقيود اللي فوق.
  4. دخل الأجهزة الخمسة بـINSERT. اكتب أسماء الأعمدة صراحة، وخلي ترتيب القيم مطابق لترتيبها.
  5. اعرض كل الأعمدة وكل الصفوف.
  6. اعرض اسم الجهاز ومكانه بس لكل الأجهزة.
  7. اعرض رقم واسم ومكان كل جهاز متاح.
  8. اعرض رقم واسم ومكان الأجهزة اللي في Lab1 ومتاحة في نفس الوقت.

لو خلصت: اعرض كل الأجهزة مرتبة باسم الجهاز، وبعدين برقمه لو الاسم اتكرر.

قبل ما تشغّل كل استعلام، توقع الصفوف اللي هتظهر من الجدول. بعد التشغيل قارن النتيجة بتوقعك، وفسّر ليه الجهاز رقم 2 ما ينفعش يظهر في آخر سؤال أساسي.

نفّذ كل INSERT مرة واحدة. حدد الأمر اللي عايز تشغّله قبل التنفيذ. لو قاعدة البيانات موجودة على الجهاز، اسأل المعيد قبل ما تكمل، وسيب الشغل الموجود زي ما هو.

استخدم ملف البداية للكتابة. ملف البيانات CSV مجرد نسخة للرجوع للبيانات، فتحه مش بيدخل الصفوف في SQL Server.

تدريب على إنشاء قاعدة بيانات وجدول، إضافة صفوف، وقراءة البيانات. مفيش UPDATE أو DELETE في التدريب ده.
