Database 1 | Week 2: build the library database

Lab02.sql is the class script with comments. Open it in SQL Server Management
Studio and read the instructions before running anything. It builds CampusLibrary
and the BookCopies table, then includes the INSERT and SELECT continuation.

The confirmed classroom checkpoint was CREATE TABLE, data types and constraints
such as NOT NULL. The later INSERT and query sections continue in Week 3.

Select and execute one statement at a time with F5 or Execute. Do not run the
whole script again if CampusLibrary or BookCopies already exist. Keep existing
work, inspect the current rows, and run each INSERT once.

Weeks 2 and 3 use CampusLibrary. Week 1's older SQL files use Database1Lab01;
change their USE line only when you intend to query the CampusLibrary table.
UPDATE and DELETE are deferred. Follow the instructions announced in class.
