How to use it, supported SQL, and differences from SQL Server

Start with All copies, change the WHERE condition, and run again. For the wishlist, load and run Create a wishlist once, then Insert two wishes once, then Read the wishlist as often as you like. Try running the same INSERT twice and inspect Messages.

  • Supported: SELECT with columns or *, DISTINCT, AS, WHERE comparisons, AND/OR/NOT, parentheses, LIKE, IS NULL, and ORDER BY ASC/DESC on one table. Also CREATE TABLE, INSERT ... VALUES, USE Database1Lab01, SELECT DB_NAME(), N'...' text, comments and GO on its own line. Separate statements with semicolons.
  • CREATE supports INT, BIT, NVARCHAR(1–4000), a single-column PRIMARY KEY, and NOT NULL. INT checks whole numbers and the SQL Server INT range; text lengths count UTF-16 units. Empty text is allowed by NOT NULL. BIT accepts only 0 or 1 here; SQL Server also converts other nonzero numeric values to 1.
  • This is a limited teaching dialect. JOIN, aggregates, TOP, UPDATE, DELETE, DROP, transactions, server setup scripts, and other T-SQL commands are not supported. Unsupported syntax shows an error. Do not paste the server preparation or transaction demos here.
  • Text equality here distinguishes upper- and lowercase; SQL Server depends on the database collation. LIKE and ordering also follow SQLite rules. Type conversion and error wording can differ. Use the Windows lab's SQL Server to verify SQL Server behaviour. Results without ORDER BY have no guaranteed order.
  • Each statement takes effect separately. Execution stops at the first error; earlier successful INSERTs or CREATEs remain. Run one statement at a time while learning. Up to 500 result rows are displayed; each table can hold up to 5,000 practice rows.
  • The editor and database are saved separately in this browser when storage is available. Reload this same file in this browser to continue. Moving the file, using another browser, private browsing, or clearing site data may lose that copy. This is browser storage, not SQL Server durability. Save .sql downloads the commands only, not a database backup.
