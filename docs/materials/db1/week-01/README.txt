Database 1 | Week 1: your first database

Open lab.html for the nine-part interactive lesson. Use English or Egyptian Arabic.
Open playground.html to type and run SQL in the browser. Keep assets/ beside it.
The playground runs offline using SQLite with a limited Lab 1 syntax adapter.
It is a practice tool, not a SQL Server instance.

Open worksheet.html for the independent tasks. Print it from your browser if needed.
The sql/ folder contains worked SELECT examples, a blank task script and a guided
ReadingWishlist table exercise. Try the tasks before checking the worked examples.

Week 1 uses the practice database Database1Lab01. Weeks 2 and 3 use CampusLibrary.
In SSMS, use the database prepared for your class. If you use the Week 1 queries
with the BookCopies table from Week 2, change USE Database1Lab01 to USE CampusLibrary.
The browser playground already includes the six BookCopies rows.

Extract the ZIP first and keep its files together. Run one selected SQL statement
at a time. Keep existing databases and tables; ask your teaching assistant if a name is
already in use. Follow the submission instructions and deadline announced in class.
